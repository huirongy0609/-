## 六、生产负向测试清单

只有部署到受保护的 Production 候选但尚未公开流量后，才执行：

- 无 Session、错误密码、错误 TOTP、伪造 Token：401；
- 普通用户后台/API：401/403；
- 审核管理员角色管理/导出：403；
- 数据管理员审核/角色管理：403；
- 超级管理员必须 AAL2；
- 登出、撤权、过期后旧 Session：401；
- 直接调用列表、导出、统计和审核 API 不得绕过权限；
- 审计 UPDATE/DELETE 必须失败；
- 日志、错误页和监控不得出现联系方式、密码、Token、数据库连接或 TOTP Secret；
- 临时迁移端点、安全探针和调试路由必须 404。

## 七、安全发布阻断项

1. Production Auth/Database 尚不存在。
2. Production Secrets 尚未配置和双人复核。
3. 真实管理员未具名、未绑定 MFA、未完成最小权限测试。
4. Production 备份/PITR 和恢复验证未完成。
5. 数据处理地域和个人信息合规责任人未批准。
6. 已验证代码未进入 release/main；正式域名仍运行较早版本。
7. `/cooperation` 和 `/cooperation/register` 在正式域名均为 404。
