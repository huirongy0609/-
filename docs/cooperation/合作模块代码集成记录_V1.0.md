```text

  └─ feature/cooperation
```

## 变更范围

- 合作登记、成功页、后台页和 `/api/cooperation-leads`。
- PostgreSQL 数据访问层、六张治理表和 COL 事务序列。
- D1 历史备份迁移演练工具。
- 服务端签名会话、MFA 声明和角色权限判断。
- 自动化校验、构建与治理文件。

未包含 DNS、生产部署、正式数据库创建、身份提供方开通、生产数据删除或 main 修改。

## 合并策略

1. feature 只承载本模块实现，完成单元测试、迁移演练和构建。
2. staging 使用 `--no-ff` 合并 feature，保留审计边界；仅允许预发布配置和验证修正。
3. release 使用 `--no-ff` 合并 staging；冻结功能范围，仅允许 P0/P1 发布阻断修复。
4. main 仅可在 No.030 具名批准、远程 Staging 验证通过、备份与回滚演练完成后合并。
5. 禁止 force-push；所有修复通过新提交进入同一链路。
