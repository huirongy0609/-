# 候选生产环境成本评估报告 V1.0

## 一、结论

在没有登录阿里云账号、地域、企业折扣、正式报价和 IDaaS 用户数的情况下，只能给出预算区间，不能形成采购金额。

```text
cost_model_ready = true
official_quote_available = false
budget_approved = false
```

建议设置两个预算场景：

- 工程候选：约 **人民币 1,500–5,000 元/月**；
- 发布等价候选：约 **人民币 3,500–12,000 元/月**。

以上为规划储备区间，不是阿里云报价。实际费用以控制台价格计算器、合同折扣、税费和账单为准。

## 二、估算假设

| 假设 | 工程候选 | 发布等价候选 |
|---|---|---|
| 地域 | 中国内地单地域 | 中国内地单地域、双可用区 |
| ECS | 1 × 2C4G | 2 × 2C4G |
| RDS | 基础/入门候选规格，仅工程验证 | PostgreSQL HA 2C4G 起，50–100GB |
| ALB | 最低可用 + 少量 LCU | 双区 + 正式健康检查/滚动发布 |
| WAF | 按量、低请求 | 按量或基础包，含安全日志 |
| CDN | 低流量、候选可不缓存动态路径 | 低到中等流量，静态资源加速 |
| 日志 | 1–5GB/月，短保留 | 5–30GB/月，按治理保留 |
| 备份 | RDS默认 + 少量 OSS | PITR + 离站/跨地域副本 |
| IDaaS | 少量测试用户 | 标准/企业能力，用户数待确认 |
| 流量 | 内部/受控测试 | 上线前压力和多网络验证 |

工程候选不能用于证明高可用或最终 RTO/RPO，只适合尽快验证容器、RDS、IDaaS 和网络链路。

## 四、计费特点

- ECS/RDS 包年包月与按量价格差异较大；候选短期可按量，但备案资源可能有购买时长和计费模式要求；
- CDN 按流量/带宽计费，并可能有 HTTPS、实时日志等增值费用；
- WAF 3.0 支持包年包月和按量，按量使用 SeCU 计费；
- SLS 按写入、存储、索引、查询等用量计费，默认开通后可能产生后付费账单；
- IDaaS 标准/企业版与账户规模、二次认证和条件访问能力相关；
- 备份超过赠送额度、跨地域或下载可能产生费用；
- 未配置费用告警和到期责任人前不得创建长期计费资源。

官方参考：[CDN计费概述](https://help.aliyun.com/zh/cdn/product-overview/billing-overview)、[WAF 3.0按量计费](https://help.aliyun.com/zh/waf/web-application-firewall-3-0/billing-description-v3/)、[SLS计费概述](https://help.aliyun.com/zh/sls/billing-overview/)、[IDaaS版本与计费](https://help.aliyun.com/zh/idaas/eiam/product-overview/pricing)。

## 五、成本控制

1. 为 Candidate 设置独立预算和 50%/80%/100% 告警；
2. 所有资源带 `environment=production-candidate`、`owner=TBD`、`expiry=TBD` 标签；
3. RDS、ECS、WAF、SLS 和 IDaaS 指定费用主责与替补；
4. CDN/WAF/SLS 使用量设置异常告警，避免攻击或日志风暴产生高额账单；
5. 工程候选验证结束后，决定升级为发布等价候选或按审批清理；
6. 不为候选购买多年期资源，除非它同时满足备案和后续生产转换的书面批准；
7. No.030-C 前输出实际 7/14/30 天账单预测。
