## 正式迁移前置条件

1. 冻结窗口开始前再次导出 D1，并核对导出数量、哈希和最大 COL。
2. Staging 执行同一工具并由数据责任人签署逐项核验。
3. 生产迁移采用先备份、导入、只读核验、切写入、冒烟测试的顺序。
4. 切换失败时停止新写入，恢复原写入端；不得删除源 D1，直至保留期和具名批准满足。

本报告支持 `migration_verified = true`（迁移程序与真实历史样本已验证），不支持宣称远程 Staging 已建立。
