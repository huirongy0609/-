## 五、职责接受要求

每位责任人必须确认：

- 已阅读相关架构、迁移、安全、回滚和审批文件；
- 理解自己的允许权限、禁止权限和一票阻断责任；
- 同意使用个人账号和 MFA，不共享账号、密码或 TOTP Secret；
- 能在发布窗口和回滚窗口到场，或已指定真实替补；
- 对审批证据、操作日志和交接记录负责；
- 离岗、换岗或到期时先撤权、再交接、后轮换相关 Secret。

## 七、完成条件

只有以下条件全部满足，才能更新：

```text
named_owners_complete = true
responsibility_signoff_complete = true
```

1. 六个核心角色主责全部具名；
2. 技术、数据、安全和发布角色均有可用替补；
3. 本人接受职责证据齐全；
4. 需要访问生产的人员已完成个人账号和 MFA；
5. 权限、有效期、交接和应急联系人已核对；
6. Project Owner 和总架构师完成最终复核。

当前不满足，状态保持 `false`。
