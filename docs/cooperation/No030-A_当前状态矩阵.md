只有至少完成以下真实签认，才应授权 No.030-B 创建 Production 候选资源：

1. 总架构师与 Project Owner 批准生产路线；

4. 正式四路径与“官网+合作模块统一生产单元”范围签认；
5. 云账号主体、预算、备案路径和 Production 资源清单批准；
6. No.030-B 授权明确允许创建哪些资源、禁止开放哪些流量，并规定回收与费用责任。

在此之前：不得修改生产 DNS、不得创建 Production 数据库、不得写入生产数据、不得合并 `main`、不得开放正式入口。
