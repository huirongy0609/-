## 四、standalone 本地运行验证

使用合成 OIDC 配置和不可达测试数据库启动，与容器相同的 `node server.js` 运行方式验证：

| 请求 | 结果 | 判断 |
|---|---:|---|
| `GET /api/health/live` | 200 | 进程存活 |
| `GET /api/health/ready` | 503 | 无数据库时正确失败关闭 |
| `GET /cooperation` | 200 | 根入口 P0 已在候选代码修复 |
| `GET /cooperation/register` | 200 | 公开表单可渲染 |
| `GET /cooperation/success` | 200 | 成功页可渲染且无必需查询数据 |
| `GET /cooperation/admin` | 307 到登录 | 未认证不显示数据 |
| `GET /cooperation/admin/login` | 200 | OIDC 登录入口可渲染 |
| `GET /api/cooperation-auth/oidc/login` | 307 到合成 IdP | state、nonce、PKCE、acr_values 与 Secure Cookie 已生成 |
| `GET /api/cooperation-leads` | 401 | 未认证管理 API 拒绝 |
| 无效 `POST /api/cooperation-leads` | 400 | 无效字段不触发数据库写入 |

本地服务启动时间约 155ms，仅是当前机器观测，不是 ECS 性能指标。

## 五、环境变量验证

静态检查使用非敏感合成配置执行，结果 PASS：

- OIDC 提供方强制；
- HTTPS 端点强制；
- 数据库 PostgreSQL scheme 与 TLS 策略；
- 候选数据库不得是 localhost/Supabase；
- MFA ACR 必填；
- 占位符拒绝。

实际 KMS Secret、RDS CA、IDaaS client 和候选域名尚不存在，因此不能认定远程环境变量通过。

## 六、登录、RBAC 与审计

已验证：

- Supabase Staging 路径保留；
- 国内候选 OIDC 授权码 + PKCE 代码构建通过；
- MFA claim 纯函数测试 2/2 通过；
- 既有 RBAC 最小权限测试 2/2 通过；
- 既有基础安全测试 4/4 通过；
- 无 Session 时管理页面 307、API 401；
- 合成数据库的审计 UPDATE/DELETE 被拒绝。

未验证：

- 真实阿里云 IDaaS 登录、TOTP 绑定和 MFA claim；
- 三角色候选测试身份；
- Session 过期、撤权和 IdP logout；
- ALB/WAF 请求头、真实客户端 IP 与 request ID；
- SLS 审计采集、告警和脱敏。

## 七、Docker/远程部署阻断

1. 当前机器无 Docker/Podman/Finch，不能实际构建和启动 `Dockerfile`；
2. 阿里云控制台未登录，无 ACR/ECS/ALB 资源；
3. 未取得资源创建预算、地域、企业账号和备案核验证据；
4. 无候选域名/证书，不能执行远程 HTTPS；
5. 无 RDS 和 IDaaS，`ready`、登录、RBAC、审计无法远程闭环。
