## 五、远程两轮验证设计

第一轮：

```text
空 RDS 候选
→ Schema Deploy
→ 合成测试数据
→ 并发 COL 验证
→ 业务读写与审计
→ 手动备份 + 记录恢复点
```

第二轮：

```text
恢复到新的隔离实例
→ 六表与约束验证
→ 数量/外键/孤儿/重复 COL
→ 最大与下一测试编号
→ 审计不可变
→ 应用重新连接与 ready=200
```

禁止在验证中删除任何正式数据；本任务本就不得访问正式数据库。
